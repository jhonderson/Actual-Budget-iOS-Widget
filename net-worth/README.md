# Net Worth Widget

It displays the daily total amount of money across all your accounts, including on budget and off budget accounts.

## 🚀 Setup

The code is in [actual-net-worth-widget.js](./actual-net-worth-widget.js), the setup steps are the same as the [Actual Budget widget](../README.md). However, it requires you to use the version `25.10.0` or later (i.e >= `25.10.0` or `latest`) of Actual HTTP API docker image.
